操作說明

基本操作

  • 從左側「圖形」面板點選或拖曳形狀至畫布。
  • 在畫布上點擊物件以選取，再於右側面板調整屬性。
  • 雙擊文字物件可直接編輯內容。
  • 按住空白鍵 + 拖曳可平移畫布；滾輪縮放畫布。

檔案

  • 支援將 SVG / PNG 直接拖曳至應用程式視窗匯入。
  • 匯入多檔時，系統自動以 item-01、item-02 規則編號。
  • 可匯出為 SVG（保留向量資訊）或 PNG（高品質點陣圖）。

快捷鍵

  • V 選擇
  • H 手型工具
  • T 文字
  • R 矩形
  • O 橢圓
  • L 直線
  • Ctrl + Z 撤銷
  • Ctrl + Y / Ctrl + Shift + Z 重做
  • Ctrl + D 原地複製
  • Ctrl + A 全選
  • Delete 刪除
  • Ctrl + S 匯出 SVG
  • Ctrl + G 建立群組
  • Ctrl + Shift + G 解散群組
  • 方向鍵 微調 1px（Shift 10px）
  • Space + 拖曳 平移畫布
  • Ctrl + 滾輪 縮放畫布
  • Shift + 拖曳 框選時加入既有選取
  • Alt + 拖曳 拖曳時暫停智慧對齊

進階操作

  • 智慧對齊：拖曳物件接近其他物件邊界 / 中線時自動吸附並顯示粉紅輔助線（按 Alt 暫停）。
  • 框選：在空白處按下拖曳即可框選多物件，Shift+框選可加入既有選取。
  • 群組：選取多物件後 Ctrl+G 建立群組，點擊任一成員即整組選取；Ctrl+Shift+G 解散。
  • 清除畫布：頂部「清除」按鈕一鍵清空（可 Ctrl+Z 還原）。
