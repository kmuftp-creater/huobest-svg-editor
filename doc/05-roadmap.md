# 未來優化方向（Roadmap）

當前版本：v0.1.1（基礎功能完成，draw.io 編輯穩定）

## 一、休息後立即可做（高 ROI）

### 1.1 打包單檔
詳見 [`04-deployment.md`](./04-deployment.md) 第三節。建立 `build.js`，一鍵產出 `svg-editor.html`。

### 1.2 雲端部署示範
選一個平台（建議 Cloudflare Pages 或 GitHub Pages）建立 demo 站，方便分享。

### 1.3 自動儲存（IndexedDB / localStorage）
當前重整就清空，需要持久化：
- 每 30 秒自動儲存目前 state.objects 至 IndexedDB
- 啟動時提示「上次未儲存的工作」可恢復
- 提供「新增專案 / 切換專案」管理

## 二、向量編輯器核心強化（中 ROI）

### 2.1 真正的鋼筆工具（v0.0.6 移除版本）
- 點擊建立錨點
- 拖曳建立貝茲曲線把手
- 雙擊轉換錨點類型（尖角 / 平滑 / 對稱）
- 雙擊已存在路徑進入錨點編輯模式
- 編輯時顯示控制把手

### 2.2 連接線（Connector）
draw.io 流程圖核心特性，當前缺少：
- 從一個物件邊緣拉出連接線
- 自動避開其他物件
- 支援箭頭、虛線、彎折樣式
- 物件移動時連接線自動跟隨

### 2.3 多選編輯
- Shift + 點擊：加入 / 移除選取
- 多選後的對齊（左 / 中 / 右 / 上 / 中 / 下對齊）
- 分布（水平 / 垂直均分）
- 批次修改屬性

### 2.4 文字進階
- 真正的雙擊進入路徑文字編輯
- Rich Text（單一文字物件內混合多種樣式）
- 文字沿路徑（textPath）
- 自動字距 / 行距控制

## 三、PRD 提及的待辦項

### 3.1 效能優化（路徑節點 > 1000 切 Canvas）
- 偵測 state.objects 中總節點數
- 超過閾值時，建立隱藏的 `<canvas>` 元素並使用 Canvas 2D API 渲染
- SVG DOM 作為「資料模型」，Canvas 作為「視覺輸出」
- 維持點擊命中（透過資料模型 hit-test，不靠 DOM）

### 3.2 字體雲端化
- 整合 Google Fonts API 動態載入
- 字型選擇器顯示 Google Fonts 完整清單
- 匯出時 inline 必要字型（避免他人開啟字型缺失）

### 3.3 PWA 離線支援
詳見 [`04-deployment.md`](./04-deployment.md) 第七節。

### 3.4 i18n（目前只繁中）
- i18next 整合
- 預設 `zh-TW`
- 加入英文（`en`）、簡中（`zh-CN`）、日文（`ja`）

## 四、UX 改進

### 4.1 上下文選單（右鍵 Menu）
- 右鍵物件 → 複製 / 貼上 / 刪除 / 群組 / 鎖定 / 帶到最上層 / 屬性

### 4.2 標尺與輔助線
- 畫布上下左右出現像素標尺
- 從標尺拖曳出永久輔助線
- 物件吸附輔助線

### 4.3 多畫板（Artboards）
- 一個檔案可有多個畫板
- 例如「桌面版」、「行動版」、「列印版」並列
- 切換顯示、批次匯出

### 4.4 取色滴管（Eyedropper）
- 從畫布任意位置吸取顏色
- 套用至選取物件的填色 / 邊線色

### 4.5 縮圖預覽（Minimap）
- 右下角小縮圖
- 顯示當前可視範圍
- 點縮圖跳轉

## 九、實作前的設計決策待確認

### 9.1 連接線資料模型
兩個候選：
- **A. 獨立物件**：connector 是一個 type，記錄起點 / 終點物件 id
- **B. 附屬於物件**：每個物件記錄自己的 connections，連接線是視覺衍生

建議 A（更彈性，但需要處理物件刪除時的連線清理）。

### 9.2 自動儲存粒度
- 每次操作後立即儲存（fine-grained，IndexedDB 寫入頻繁）
- 30 秒節流儲存（粗粒度，可能丟失 30 秒內變更）
- 操作觸發 + 失焦觸發（折衷）

建議第三方案。

### 9.3 模組化打包工具
- 維持無 build：用 ES Module（`<script type="module">`）拆分檔
- 加入 Vite：更複雜但功能強

建議先用 ES Module，必要時再導入 Vite。
