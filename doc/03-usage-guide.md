# 使用者操作指南

## 一、啟動方式

### 本地直接開啟
1. 用瀏覽器（Chrome / Edge / Firefox / Safari）開啟 `index.html`
2. 第一次載入會從 Google Fonts CDN 下載字型（約 200 KB）
3. 啟動後即為空白畫布，無需註冊

### 建議瀏覽器
- Chrome / Edge：最佳支援
- Firefox：完整支援
- Safari：完整支援（含 macOS / iOS）

## 五、屬性面板

### 物件樣式
- 預設色卡（8 色）：點擊套用至選取物件
- 填滿：顏色 + 啟用 checkbox
- 漸層：reserved（未實作）
- 邊線：顏色 + 樣式（實線 / 虛線 / 點線 / 點虛線）+ 寬度
- 周長：顯示
- 不透明度：0~100%
- Sketch / 陰影：effect 開關
- 編輯：複製樣式 / 貼上樣式 / 重設樣式
- 設為預設樣式

### 文字
**最上方文字內容區（textarea）**：
- 直接顯示選取物件的文字
- 即時雙向綁定，輸入時畫布同步更新
- 支援多行（Shift+Enter 或直接按 Enter）
- 按 Esc 取消、Tab 離開

**字型**：11 種預設字型（Helvetica / Verdana / Times / Garamond / Comic Sans / Courier / Georgia / Lucida Console / Tahoma / Noto Sans TC / 微軟正黑體）

**樣式按鈕**：B / I / U / S + 字級

**對齊**：左 / 中 / 右 / 上 / 中 / 下

**位置 / 書寫方向**：reserved

**顏色**：文字 / 背景 / 邊框 + 陰影開關

**進階**：自動換行 / 格式化文字 / Convert labels to SVG / 不透明度 / 間距 / Padding

### 調整
- 圖層次序：移到最上層 / 最下層 / 上移一層 / 下移一層
- 大小：W / H（限制寬高比 checkbox）
- 位置：X / Y
- 角度：° + 旋轉 90° 按鈕
- 翻轉：水平 / 垂直
- 對齊：Snap to Grid 切換
- 群組 / 複製大小 / 重設 / 鎖定 / 解鎖 / Explore

## 六、檔案操作

### 匯入
| 方式 | 操作 |
|---|---|
| 工具列 | 點「開啟」按鈕選檔 |
| 拖曳 | 把檔案從桌面拖入瀏覽器視窗 |

支援格式：`.svg`、`.png`、`.jpg`、`.jpeg`

匯入時的自動處理：
- 大尺寸自動縮放至畫布大小（保留 5% 邊距）
- 多檔依順序自動編號（item-01、item-02、...）
- draw.io 格式自動偵測並啟用 ghost 文字模式

### 匯出
| 按鈕 | 格式 | 用途 |
|---|---|---|
| 匯出 SVG | `.svg` | 向量保留，可在其他工具編輯 |
| 匯出 PNG | `.png` | 高品質點陣圖，1200×800 px |

檔名格式：`design-{timestamp}.svg / .png`

### 清除畫布
頂部「清除」按鈕：
- 跳出確認對話框（顯示物件數量）
- 寫入歷史紀錄，**可用 Ctrl+Z 還原**

## 七、進階操作

### 編輯文字
**方法 1：雙擊**
- 在畫布上雙擊文字物件 → 跳出藍色描邊內嵌編輯器
- Enter 提交、Esc 取消、Shift+Enter 換行

**方法 2：屬性面板（推薦）**
- 選取文字物件 → 右側面板自動切到「文字」分頁
- textarea 顯示當前文字 → 直接編輯
- Tab / 點其他位置 → 套用並寫入歷史

**draw.io 匯入的文字**：
- 圖層列表會看到 `T` 紫色前綴標示的 Ghost 物件
- 點圖層 → 自動平滑捲動 + 藍光暈閃爍定位
- 編輯後，compound shape 內對應的 foreignObject 同步更新

### 智慧對齊
拖曳物件時：
- 接近其他物件邊界（左 / 中 / 右 / 上 / 中 / 下）時自動吸附
- 顯示粉紅虛線輔助線指示對齊軸
- 距離閾值：6 px
- **按住 Alt 暫停對齊**，可精確自由微調

### 框選多物件
- 在空白處拖曳出虛線矩形
- 框內物件即時被選取
- **Shift + 框選** 可加入既有選取
- 同群組成員自動一起選取

### 群組
- 選 2+ 物件 → **Ctrl+G** 建立群組
- 群組成員以紫色虛線外框包覆顯示
- 點任一成員（畫布）→ 整組選取
- **Ctrl+Shift+G** 解散群組
- 圖層面板點擊不擴展（可單獨選取群組內成員）

### 圖層 / 歷史紀錄面板
右側面板底部：
- **圖層**：列出所有物件
  - `●` / `◌` 切換可見性
  - 色塊：物件 fill 顏色
  - 鎖頭：鎖定 / 解鎖
  - **點擊**：選取並自動平滑捲動置中 + 藍光閃爍
  - Shift+點擊：多選
- **歷史紀錄**：列出每筆操作
  - 點擊跳至該歷史點

底部標題列右側 ▾ 按鈕：收摺 / 展開整個底部區。

## 九、常見問題

### Q1：匯入 draw.io 流程圖後，圖層列表有大量 `text-XX` 紫色 T 物件，能刪嗎？
**A**：不建議。這些是 Ghost 物件，用於提供文字編輯介面。刪除後雖然視覺不變（compound 仍顯示原文字），但失去編輯能力。若不需要編輯，可保留不管。

### Q2：在 textarea 編輯文字，畫面變慢？
**A**：對於 80 KB+ 的大型 SVG，textarea 輸入加了 80 ms debounce 才會同步到 compound（避免每鍵全量重序列化）。即時 UI（layer list、提示文字）仍每鍵更新。

### Q3：暗色模式下匯入的 SVG 顏色不對？
**A**：draw.io 的原始填色（含漸層）會完整保留，不會被主題覆寫。若要套用主題色，請選取後手動更改填色。

### Q4：如何匯出時去除背景？
**A**：目前匯出 SVG 會保留白色背景。可匯出後手動編輯 SVG 移除 `<rect fill="#ffffff" />` 那一行。

### Q5：可以多人協作嗎？
**A**：目前是純前端應用，無後端，無協作功能。資料只存於瀏覽器當前 session（無 localStorage 儲存物件狀態，重新整理會清空）。

### Q6：如何儲存目前工作？
**A**：目前唯一方式是「匯出 SVG」存檔，下次再「開啟」匯入。自動儲存功能在 roadmap 中。

## 十、效能限制
| 項目 | 上限 / 建議 |
|---|---|
| 物件數量 | 建議 < 500（超過會卡） |
| 路徑節點 | 建議 < 1000（PRD 提及未來切 Canvas 渲染） |
| 歷史紀錄 | 固定 50 筆，超過自動丟最舊 |
| 匯入 SVG | 建議 < 500 KB |
| 匯入 PNG | 建議 < 10 MB |
| 畫布大小 | 固定 1200 × 800 |
