# 🎨 SVG 專業向量編輯與文字處理軟體 (PRD)

### 🎯 核心功能 (Core Features)
- **SVG 向量路徑解析**：完整讀取並解析 SVG 檔案架構，支援路徑 (Path)、矩形 (Rect)、圓形 (Circle)、橢圓 (Ellipse)、線段 (Line) 及多邊形 (Polygon)。
- **文字圖層精準編輯**：專為文字設計的編輯引擎，能讀取 `<text>` 標籤及其 `font-family`, `font-size`, `fill` 等屬性，並允許使用者直接在畫布上修改內容。
- **影像讀取與寫入**：支援 PNG 檔案匯入作為參考圖層或背景，並可將編輯完成的向量稿件導出為高品質 PNG 或向量 SVG。
- **智慧上傳 (Smart Upload)**：提供支援拖曳上傳 (Drag & Drop) 的互動區塊，使用者可將檔案從桌面直接拖曳至應用程式視窗進行編輯。
- **自動編號 (Auto Numbering)**：上傳多個圖檔或物件時，系統將依據檔案順序自動新增邏輯編號（如 item-01, item-02）以利圖層管理。
- **歷史紀錄 (History System)**：具備完整的操作紀錄查詢面板，支援撤銷 (Undo) 與重做 (Redo) 每一項編輯步驟。
- **多國語言支援 (Multi-language)**：介面完全支援繁體中文，符合台灣在地化語系。

### 🎨 視覺與介面 (Visual & Interface)
- **設計風格**：採用霍家私塾標準，以中性色為基底，搭配 `#4A90E2` (原色藍) 作為主色，用於關鍵按鈕與選取狀態。
- **頂部導覽列 (Header)**：採用置中容器佈局，最大寬度設為 `max-w-7xl`，確保在寬螢幕下兩側仍保有優雅留白，不緊貼邊緣。
- **主題切換按鈕 (Theme Toggle)**：
    - **樣式**：膠囊型 (Pill-shaped) 細邊框按鈕。
    - **亮色模式**：背景純白，顯示「金黃色月亮圖示」與「暗色」字樣。
    - **深色模式**：背景深灰藍 (`#1A2233`)，顯示「亮黃色太陽圖示」與「亮色」字樣。
- **教學說明按鈕 (Help Modal)**：膠囊型設計，內含鮮藍色書本圖示與「說明」文字，點選後彈出操作指南視窗。
- **卡片與佈局**：編輯面板使用 12px 圓角與輕微擴散陰影，遵循 4px/8px 網格系統，確保視覺平衡。

### 📱 響應式與互動 (Responsive & Interaction)
- **滑鼠互動**：支援滑鼠滾輪縮放畫布及點擊選取向量路徑。
- **彈性佈局**：屬性面板在寬螢幕下固定於右側，在行動裝置或窄視窗下自動調整為收摺模式。

### 🔧 技術特色 (Technical Highlights)
- **即時渲染引擎**：基於瀏覽器原生 SVG DOM 操作，確保編輯過程零延遲。
- **色彩語義化**：系統化定義 Success (`#5AC8A5`)、Error (`#F06292`) 等語意色彩。

### 建議與補充
1. **效能優化 (Performance)**: 當 SVG 路徑節點超過 1000 個時，從 SVG DOM 切換至 Canvas 渲染以提升效能。
2. **層級管理 (Layer Locking)**: 增加圖層鎖定功能，防止使用者在編輯文字時誤觸背景向量路徑。
3. **字體雲端化 (Cloud Fonts)**: 整合 Google Fonts，解決本地字體缺失導致 SVG 文字渲染不一致的問題。
4. **快捷鍵支援 (Hotkeys)**: 增加常見的向量編輯快捷鍵，如 `V` (選擇)、`T` (文字)、`Ctrl+Z` (復原)。
